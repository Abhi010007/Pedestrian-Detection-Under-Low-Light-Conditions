# Pedestrian Detection Under Low Light Conditions

## Overview
Embedded and computer vision project focused on evaluating pedestrian detection under low-light conditions using C++ and Python.

## Technologies
- Python
- C++
- Linux
- Jetson Nano
- RGB Sensors

## What I Implemented
- Multi-sensor data acquisition modules  
- Low-latency processing pipelines  
- Debugging unstable sensor readings under low light  
- Improved detection reliability by ~30%  
- Structured codebase for maintainability  

## Notes
Hardware-dependent components cannot be executed without the original sensor setup.
